MY STRENGTH COACH — VERSION 2

Includes set-by-set logging, automatic progression suggestions, personal records, exercise instructions, simplified diagrams, online technique-video buttons, a rest timer, workout history, spin settings and data export.

INSTALL
1. Unzip the package.
2. Upload all files to a free static host such as GitHub Pages, Cloudflare Pages or Netlify.
3. Open the hosted address on your phone.
4. iPhone: Safari > Share > Add to Home Screen.
5. Android: Chrome > menu > Install app or Add to Home Screen.

Videos require internet access. Workout data is stored locally on the device, so export a backup regularly.
